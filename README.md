# Countdown Timer ⏱️

A simple, elegant countdown timer web application built with HTML, CSS (Tailwind CSS), and vanilla JavaScript. This project provides a clean, responsive interface for setting and tracking countdowns with visual feedback.

## Features ✨

- **Custom Time Input**: Set hours, minutes, and seconds for your countdown
- **Visual Alerts**: 
  - Background changes to yellow when 2 minutes remain
  - Background changes to red with pulse animation when 1 minute remains
- **Control Buttons**: Start, Stop, and Reset functionality
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Mobile-Optimized**: iOS/Safari specific fixes for better mobile experience
- **Clean UI**: Modern interface using Tailwind CSS

## Files Description 📁

- **timer.html** - Main countdown timer with enhanced features (Stop/Reset buttons, color warnings)
- **timer copy.html** - Duplicate of the main timer file
- **test.html** - Basic countdown timer implementation
- **timerCardIndex.html** - Alternative timer design with card-style UI

## Technologies Used 🛠️

- **HTML5** - Structure and markup
- **Tailwind CSS** - Styling via CDN
- **JavaScript** - Timer logic and interactivity
- **CSS3** - Custom styling and animations

## How to Use 🚀

1. **Clone or Download** this repository
   ```bash
   git clone https://github.com/fvargas809/Countdown-Time.git
   ```

2. **Open the HTML file** in your web browser
   - Simply double-click `timer.html` or any other HTML file
   - Or open it through your browser's File > Open menu

3. **Set Your Timer**
   - Enter the hours, minutes, and seconds
   - Click "Start Timer"
   - Watch the countdown with visual feedback:
     - White background: Normal countdown
     - Yellow background: 2 minutes remaining
     - Red pulsing background: 1 minute remaining

4. **Control Your Timer**
   - **Stop**: Pause the countdown
   - **Reset**: Clear and restart the timer
